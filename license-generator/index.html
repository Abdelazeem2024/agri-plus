🔐 أداة توليد أكواد التفعيل

هذه الصفحة إرشادية فقط — التوقيع الرقمي الحقيقي (Ed25519) يحتاج المفتاح الخاص، ولا يجوز أبداً وضعه داخل صفحة ويب (حتى لو كانت محلية) لأن أي ملف HTML يمكن فتحه ونسخ محتواه بسهولة. لذلك يتم التوليد الفعلي فقط عبر سطر الأوامر التالي على جهازك أنت:

  1. أول استخدام فقط — ولّد زوج مفاتيح لهذا البرنامج: node keygen.cjs
  2. الصق المفتاح العام الناتج داخل electron/license.cjs (مكان PUBLIC_KEY_PEM) في المشروع الرئيسي.
  3. لكل عميل جديد، اطلب منه بصمة الجهاز (Machine ID) من شاشة الإعدادات → زر "نسخ"، ثم: node generate.cjs <MACHINE_ID> PERM node generate.cjs <MACHINE_ID> YEAR 1
  4. أرسل الكود الناتج للعميل، فيلصقه في شاشة "إدخال كود التفعيل" داخل البرنامج.
⚠️ لا ترفع مجلد keys/ ولا issued/ على GitHub أو أي مكان — هما محميان بالفعل عبر .gitignore، ويحتويان على المفتاح الخاص وسجل تراخيص عملائك.
